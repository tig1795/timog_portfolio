Machine LearningMaster's thesis · 1.0Masterarbeit · 1,0

Hit Song Prediction

What makes a song a hit? I built my own dataset of Billboard chart songs from 1960 to 2015, with audio features from the Spotify Web API and sentiment and emotion scores for the lyrics from pretrained Transformer models. Using XGBoost, I compared it with a much larger dataset of 41,106 songs. Popularity and danceability turned out to be the most informative features. Was macht einen Song zum Hit? Ich habe einen eigenen Datensatz mit Billboard-Songs von 1960 bis 2015 aufgebaut, mit Audiomerkmalen aus der Spotify Web API und einer Stimmungs- und Emotionsanalyse der Songtexte durch vortrainierte Transformer-Modelle. Mit XGBoost habe ich ihn mit einem deutlich größeren Datensatz von 41.106 Songs verglichen. Am aussagekräftigsten waren Popularität und Tanzbarkeit.
